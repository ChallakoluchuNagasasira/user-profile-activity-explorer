User Profile & Activity Explorer

How to run:
1. Extract the user-explorer folder.
2. Open the folder in VS Code.
3. Install the VS Code extension "Live Server" if you do not have it.
4. Right-click index.html and choose "Open with Live Server".
5. Enter a User ID from 1 to 10 and click Search User.

Features:
- User ID validation before API requests
- Random User button
- User profile fetched with async/await
- First 3 posts displayed
- View Comments toggle for each post
- Bookmark / remove bookmark using localStorage
- Saved users list in the sidebar

API used:
https://jsonplaceholder.typicode.com/

Note:
Internet connection is needed to fetch API data.
